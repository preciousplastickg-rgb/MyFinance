# Отчёты v2 — макет для этапа 22

Требования — в `docs/SPEC.md`, раздел 6 (блоки с пометкой «этап 22»), 7b и строка 22 в разделе 10. Этот каталог — только картинка к ним; при расхождении прав SPEC.

- `01–03-money-*.png` — отчёт по деньгам за октябрь 2026: итог месяца и темп, кольцо с легендой и «Обязательные / переменные», «По счетам» + «Доходы» + «Где сократить». Светлая и тёмная тема, 390×844 @2x.
- `04–05-tasks-*.png` — «Дела» неделя и месяц. Совпадают с текущим SPEC 7.3, в этап 22 не входят — для сверки.
- `MyFinanceReports-4a.dc.html` — исходник прототипа. Смотреть только ветки `vD`, `isTasks` и функции `ACCS`, `flowsOf`, `renderVals` (блоки `// D:` и `// accounts`). Варианты a/b/c и вкладка «Счета» — отклонённые, не переносить. `<sc-if>`, `{{ }}`, `DCLogic` — рантайм макета, в код не тащить. Открыть в браузере можно рядом с `../reference/support.js`.

Цифры в макете выдуманы (месяцы до сентября, разбивка по дням, движение по счетам). Сверять с seed-данными по правилам SPEC, а не с картинкой.
