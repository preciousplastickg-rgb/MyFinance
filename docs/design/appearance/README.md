# Оформление — макет для этапа 26

Требования — `docs/SPEC.md`, раздел 9a и строка 26 в разделе 10. Этот каталог — картинка и готовые токены к ним; при расхождении прав SPEC.

- `themes.css` — токены трёх тем (Графит, Синий, Эспрессо) × светлая/тёмная и светлого меню. Перенести в `src/tokens.css` после существующих блоков; `data-palette` на `<html>`.
- `*-center-*.png` — «+» по центру в трёх темах, светлая и тёмная. `graphite-left-*`, `graphite-right-*` — «+» сбоку. `settings-appearance-*` — окно «Оформление». 390×844 @2x.
- `MyFinanceApp2-appearance.dc.html` — исходник прототипа (открывать рядом с `../reference/support.js`). Смотреть: `PAL` (navy, espresso), `tokens()`, ветки `cPill` (меню с вырезом) и `navSide` с `lightNav`, окно `sheetLook`, расчёты `fabLight`, `side`, `navC`, `lookThemes`. Варианты `notch-bar`, `split`, `op1` — отклонённые, не переносить. `<sc-if>`, `{{ }}`, `DCLogic` — рантайм макета.

Экран «Сегодня» на картинках — старый (до этапов 24–25). Меняются только цвета и меню, содержимое экранов остаётся как в коде.
