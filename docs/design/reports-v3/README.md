# Отчёты v3 — макет для этапа 30

Требования — `docs/SPEC.md`: раздел 6 (строки «Куда ушли деньги» и «Детализация»), 7.3 и строка 30 в разделе 10. Здесь только картинка; при расхождении прав SPEC.

- `money-rating-*.png` — «Отчёты → Деньги»: блок «Куда ушли деньги» вместо кольца. Кафе раскрыто тапом.
- `tasks-burnup-week-*.png`, `tasks-burnup-month-*.png` — «Отчёты → Дела»: нарастание, флажки важных, четыре плитки, строка выбранного дня.
- `MyFinanceReports.dc.html` — исходник «Денег», смотреть только вариант `a` (`vA`, массив `rows`). `MyFinanceTaskChart.dc.html` — исходник «Дел», вариант `e` (`vD` + `showFlags`, объекты `bu`, `tiles`, `cap`). Остальные варианты отклонены. Открывать рядом с `../reference/support.js`.

Цифры выдуманы. В макете разница к среднему показана от 5% — в приложении по SPEC от 10%. Анимации в макете есть, в приложении их нет (этап 29: анимирована только смена темы).
