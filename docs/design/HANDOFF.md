# MyFinance — редизайн по варианту 2e «Графит + коралл»

Задача для Claude Code: перенести утверждённый дизайн 2e на существующий код приложения (offline PWA для iPhone). Дизайн утверждён, ничего в нём не придумывать и не «улучшать». Данные, хранилище и бизнес-логика остаются из текущего приложения — меняется визуальный слой и добавляются экраны/взаимодействия, которых пока нет.

## Что в папке

- `HANDOFF.md` — этот файл, главный источник требований.
- `tokens.css` — все цвета светлой и тёмной темы, радиусы, шрифты, тени. Подключить как есть, переименовать переменные под конвенцию проекта можно.
- `screens/*.png` — эталонные скриншоты 390×844 @2x, светлая и тёмная тема: Сегодня, Деньги, Дела, Цели, Отчёты, Новая запись.
- `reference/MyFinanceApp2-2e.dc.html` — исходник прототипа. Разметка с inline-стилями (точные px, отступы, радиусы) + класс `Component` с логикой (строки ~709–1353). Читать как спецификацию, НЕ копировать в проект: `<sc-if>`, `<sc-for>`, `{{ }}`, `DCLogic` и `support.js` — рантайм редактора дизайна, в приложении их быть не должно.
- `reference/support.js` — рантайм прототипа, нужен только чтобы открыть reference в браузере.

В reference уже выставлены нужные значения по умолчанию: `palette=graphite`, `hero=bars`, `habits=compact`, `nav=float`. Ветки других вариантов (`heroRing`, `heroWithBars`, `hvWeek` на «Сегодня», `hvTiles`, `navBar`, `navLabels`) — игнорировать, их не переносить. Таблица `PAL` с остальными палитрами — тоже.

## Порядок работы

1. Сначала изучить текущий репозиторий: стек, где лежат стили/тема, компоненты экранов, модель данных (счета, транзакции, регулярные платежи, дела, привычки, цели — если есть). Составить таблицу соответствия «экран/блок прототипа → файл/компонент проекта» и показать её мне до правок.
2. Подключить `tokens.css` и шрифты (см. «Офлайн»), перевести все существующие цвета на переменные. Хардкод hex в компонентах после этого шага не допускается.
3. Переверстать экраны по порядку: оболочка (меню + FAB + тост) → Сегодня → Новая запись → Деньги → Дела → Цели → Отчёты → шторки и вложенные экраны.
4. Добавить недостающие функции (раздел «Поведение»).
5. Проверка по чек-листу в конце, сравнение со `screens/*.png` в обеих темах.

Коммитить по шагам, один шаг — один коммит.

## Дизайн-система

Цвета — `tokens.css`. Ключевое:
- Почти монохром: графитовый `--primary` (в тёмной теме — светлый), коралл `--accent` только для акцентов: активная вкладка меню, бейдж «до зарплаты N дней», рамка «сегодня» у привычек, точки в календаре, кнопка «Отменить» в тосте.
- `--income` — суммы доходов, «Записано». `--warn` — перерасход, просрочено, «завтра» у платежа, флажок важного дела, рост категории ≥ 20%.
- Цвет категории/привычки/цели — палитра `--c-*`, применяется только через иконку в кружке (класс `.ic` в tokens.css: тинт 13% / 26% в тёмной).

Типографика:
- UI — Golos Text, базовый 15px / 1.4. Заголовок экрана 28px/600 (дата на «Сегодня» — тоже 28px). Заголовок секции 17px/600. Подписи 12–13px `--muted`.
- Крупные цифры — Unbounded 600, `letter-spacing: -0.03em`, `font-variant-numeric: tabular-nums`: лимит 44px, проценты целей 17px, центр донат-диаграммы в отчётах.
- Все суммы — `tabular-nums`. Разделитель тысяч — неразрывный пробел (U+00A0): `1 850`, не `1,850`. Минус — типографский `−` (U+2212), не дефис.

Геометрия:
- Экран 390×844, контент `padding: 56px 0 128px` (под статус-бар и плавающее меню), горизонтальные поля 16px, gap между секциями 16px.
- Карточка: `--surface`, радиус 24px, `--shadow`. Строки внутри карточки разделяются `1px solid var(--line)` (у первой строки нет).
- Контролы: радиус 16px. Тап-зона любой кнопки ≥ 44×44 (у галочки визуал 22px, но кнопка 44px).
- Иконки — Lucide (`lucide-static@0.460.0`), размеры 16/17/21/28px. Список используемых имён — в `CATS`, `GOAL_ICONS` и разметке reference.

## Оболочка

- Плавающее меню: `left/right 16px, bottom 30px`, высота 64px, радиус 32px, фон `--nav-bg`, тень `--shadow-nav`. 5 вкладок без подписей: Сегодня `calendar-days`, Деньги `wallet`, Дела `list-checks`, Цели `target`, Отчёты `chart-pie`. Активная — пилюля 52px высотой, фон `--nav-pill` (коралл), иконка `--nav-pill-ink`. Неактивные — `--nav-ink`. `aria-label` = название вкладки.
- FAB «+» справа от меню, 64×64, круг, `--primary` / `--on-primary`, тень `--shadow-fab`, открывает «Новая запись» (расход по умолчанию).
- Переход по вкладке сбрасывает открытые вложенные экраны (цель, «Регулярные», день).
- Тост: над меню (`bottom: 108px`), фон `--ink`, текст `--bg`, иконка `check`. Для действий с отменой — кнопка «Отменить» цветом `--toast-action`, тост живёт 5 с; без отмены — 3 с. Новый тост заменяет старый.
- Safe-area: в прототипе отступы зашиты под iPhone с Dynamic Island. В приложении — через `env(safe-area-inset-top/bottom)`, `bottom` меню = `max(30px, env(safe-area-inset-bottom) + 16px)`.

## Экраны

Сегодня (`isToday`, `screens/01-today-*.png`):
- Шапка: день недели 13px `--muted`, дата 28px + `chevron-down` — тап открывает шторку календаря. Справа кнопки «Тема» (moon/sun) и «Настройки».
- (Этап 24: карточка лимита заменена карточкой «Остаток» — SPEC 4.10 и 5.1 п. 3; столбики дней не переносятся, лимит остаётся одной строкой внизу.)
- Карточка лимита, вариант `heroBars`: «Можно тратить сегодня» + бейдж «до зарплаты N дней» (`--sunk` фон, `--accent` текст); число лимита 44px Unbounded + «сом»; 6 столбиков дней до поступления (высота 44px, радиус 12px, фон `--sunk`): первый (сегодня) залит снизу на долю ОСТАТКА `--hero-fill`, при перерасходе `--warn`; остальные — `--hero-fill-soft` на 100%. Подписи дней 11px, сегодня 700 `--ink`. Строка «Потрачено X» / «Осталось Y» (или «Перерасход Y» цветом `--warn`). Внизу кнопка-строка на `--sunk` с формулой «на счетах − обязательных = свободно на N дней» → шторка «Из чего лимит».
- Счета: свёрнутый заголовок «Всего ≈ …», раскрывается. USDT — с пунктирной обводкой иконки, подпись «вне лимита», пересчёт в сом и строка «USDT не входит в лимит · курс … от …».
- Цели: до 3 карточек с кольцом прогресса 52px, процент Unbounded 17px, строка «деньги 38% · привычки 61% · дела 1 из 3».
- Платежи до поступления: строки с кнопкой «Оплачено» → состояние «Записано» (`--income`) → через 2 с строка исчезает; тост с отменой. Пусто — «До зарплаты всё оплачено».
- Дела: группы «Сегодня, …» / «Завтра, …», важные сверху, флажок `--warn`, чип цели.
- Привычки, вариант `hvCompact`: строка 60px — иконка 32px, название, 7 точек недели 12px, «N дн.» серии, справа круг 30px «отметить сегодня» (рамка 2px `--accent`, выполнено — заливка цветом привычки + check).

Новая запись (`entry`, `06-entry-*`): сегмент Расход/Доход/Перевод; сумма крупно (расход `−`, доход `+` цветом `--income`); 5 частых категорий + «Ещё…» (шторка со всеми категориями и «Новая»); перевод — откуда/куда; цифровая клавиатура 3×4 (`1–9, 00, 0, ⌫`, кнопки 52px `--sunk`), максимум 9 цифр, ведущий 0 игнорируется; «Сохранить» активна только при сумме > 0 и выбранной категории (для перевода — только сумма). Ввод за 3 тапа: сумма → категория → «Сохранить». Перевод не считается расходом и не уменьшает лимит.

Деньги (`isMoney`): поиск (иконка в шапке → поле, фильтр по категории/заметке/счёту/сумме, итог «Найдено N · расходы X сом» или «Ничего не нашлось»); чипы счетов (активный — `--primary`); история по дням с итогом дня; тап по заголовку дня → экран дня; вход в «Регулярные».

Дела (`isTasks`): сегмент Задачи/Привычки. Задачи: поле «Новая задача на сегодня» (Enter добавляет), вкладки Сегодня/Предстоящие/Без даты/Выполненные со счётчиками, активная — `--ink` фон, `--bg` текст. Привычки — полный список с неделей пн–вс, серией, лучшей серией, % выполнения, чипом цели.

Цели (`isGoals`): список целей + «Новая». Экран цели: большое кольцо, разбивка Деньги/Привычки/Дела, копилка с планом «по X в месяц до даты», «Пополнить» и «Снять», связанные привычки и дела, «Связать» (шторка привязки/отвязки), поле нового дела прямо в цели.

Создание цели (`create`): название, значок (12 шт., `GOAL_ICONS`), цвет (6 шт., `GOAL_COLORS`), срок (3 месяца / Полгода / Год / Без срока), переключатель копилки + сумма + расчёт «по X сом в месяц», выбор привычек и дел (с пометкой «сейчас ведёт к …»), добавление нового дела. «Создать» активна при непустом названии.

Отчёты (`isReports`): сегмент Деньги/Дела/Привычки. Деньги — донат по категориям (тап по сегменту выделяет его: толщина 26→34, остальные opacity .3, в центре сумма и % категории), легенда с дельтой к среднему, блок «Где можно сократить». Дела — столбики по дням недели «сделано/запланировано», плитки Сделано/Осталось/Просрочено. Привычки — по reference.

Шторки и вложенные экраны: календарь месяца (дни с записями — точка `--accent`, сегодня — заливка `--primary`), экран дня (расходы/доходы дня, привычки дня с отметкой, «+» с датой этого дня, стрелки пред./след. день), «Из чего лимит» (4 строки, каждая ведёт на свой экран), «Регулярные» (группы Доходы / Платежи / Подписки с суммой в месяц; редактирование суммы, переключатели «Обязательный» — резервируется в лимите, «Подписка» — попадает в «Где можно сократить»; удаление с отменой).

## Поведение, которое надо сохранить или добавить

Проверить по коду, чего в текущем приложении нет, и добавить. Логика — в методах `Component` reference:
- `flash(text, undo)` — тост с отменой для: сохранения записи, оплаты платежа, пополнения/снятия копилки, удаления регулярного.
- `save()` — запись/перевод/операция с копилкой. Снятие из копилки не больше остатка.
- `pay(p)` — open → paid → через 2 с скрыт.
- `goalView(g)` — прогресс цели = среднее по имеющимся частям (деньги = накоплено/цель, привычки = средний % связанных, дела = выполнено/всего). Части без данных не участвуют.
- `habitView(h)` — состояния точки недели: выполнено, пропущено (запланировано, не сделано, в прошлом), сегодня (рамка `--accent`), будущее/не запланировано (opacity .4). Отмечать будущие дни нельзя. Привычка с флагом «кафе» показывает предупреждение `--warn`, если сегодня есть расход в «Кафе».
- `saveGoal()` — новая цель + привязка выбранных привычек и дел.

## Что в прототипе захардкожено — в приложении считать из данных

Не переносить буквально:
- Лимит `LIMIT = 1850`, «27 600 на счетах», «16 500 обязательных», «11 100 на 6 дней», «6 дней до зарплаты», «Всего ≈ 71 350 сом», курс USDT 87,50 — брать из текущей формулы лимита в приложении. Контрольный пример из SPEC: лимит 1 850, после трат 640 остаётся 1 210.
- Подписи дней у столбиков (`Ср…Пн`) — от сегодня до дня поступления, их число = дни до поступления (если > 7 — решить со мной, в дизайне 6).
- «Сегодня уже 250 сом в «Кафе»» — сумма реальных трат в «Кафе» за сегодня.
- Даты «4 ноября», `TODAY = 2`, ноябрь в календаре, отчёты «Октябрь 2026», данные `R`, `cuts`, `taskBars`, `taskTiles` — из реальных данных.
- Все массивы в `state` (tx, recurring, payments, tasks, habits, goals, jars) — тестовые данные прототипа, в проект не попадают.

## Офлайн (обязательно)

Прототип грузит Golos Text и Unbounded с Google Fonts и Lucide с unpkg — для offline PWA так нельзя.
- Шрифты: self-host woff2 (`@fontsource/golos-text` 400/500/600/700, `@fontsource/unbounded` 500/600/700, подмножества cyrillic + latin), `font-display: swap`.
- Иконки: только используемые Lucide как inline SVG / спрайт (через `lucide` пакет или вырезать из `lucide-static@0.460.0`), не весь icon-font.
- Добавить шрифты и спрайт в precache service worker. Проверка: в авиарежиме после первой загрузки экраны выглядят как на скриншотах.

## Тема

Переключатель луна/солнце в шапке «Сегодня» ставит `data-theme="dark"` на корень. Выбор сохранять в хранилище приложения. Если выбора нет — следовать `prefers-color-scheme`. Обновить `<meta name="theme-color">` под `--bg` текущей темы.

## Известные огрехи прототипа — исправить при переносе

- Вкладки задач «Сегодня / Предстоящие / Без даты / Выполненные» не помещаются в 390px, «Выполненные» переносится на вторую строку (видно на `03-tasks-*.png`). Сделать горизонтальный скролл без переноса (`white-space: nowrap; overflow-x: auto`, скрытый скроллбар).
- Нет поддержки safe-area (см. «Оболочка»).
- Числа форматируются через `Math.round` — копейки/тыйыны и USDT с дробной частью (`500,00`) форматировать отдельно, запятая как десятичный разделитель.

## Чек-лист приёмки

- [ ] Все 6 скриншотов совпадают визуально в светлой и тёмной теме (цвета, шрифты, радиусы, отступы).
- [ ] В компонентах нет hex/rgb, кроме `#fff` на кнопках и в `tokens.css`.
- [ ] Лимит: при тратах 640 из 1 850 показывает «Осталось 1 210», первый столбик заполнен на 65%; при перерасходе — «Перерасход», `--warn`.
- [ ] Новая запись за 3 тапа, тост с «Отменить» откатывает запись.
- [ ] Цель: прогресс считается по формуле `goalView`, «Пополнить»/«Снять» работают, перевод в копилку не уменьшает лимит.
- [ ] Регулярные: правка суммы, переключатели, удаление с отменой.
- [ ] Офлайн в авиарежиме: шрифты и иконки на месте.
- [ ] Все тап-зоны ≥ 44px.
